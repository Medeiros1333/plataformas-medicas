# 01_Examenes_Anteriores

Aquí van los exámenes MIR de años anteriores, con su plantilla de respuestas, organizados por año.

## Estructura esperada

```
01_Examenes_Anteriores/
├── 2024/
│   ├── Examen_MIR_2024.pdf
│   └── Plantilla_Respuestas_MIR_2024.pdf   (preferir la versión "_definitiva" si existe)
├── 2023/
│   ├── Examen_MIR_2023.pdf
│   └── Plantilla_Respuestas_MIR_2023.pdf
└── ...
```

## Qué aportar

- El **cuadernillo del examen** completo de cada año disponible (idealmente los últimos 8-10 años, cuantos más mejor para robustecer el banco de preguntas reales).
- La **plantilla de respuestas oficial**. Si el Ministerio de Sanidad publicó tanto una versión **provisional** como una **definitiva** (tras el plazo de reclamaciones/impugnaciones), aportar preferentemente la **definitiva** — es la fuente autoritativa. Si solo se tiene la provisional, nombrarla claramente como tal (ej. `Plantilla_Respuestas_MIR_2024_provisional.pdf`) para que quede marcada como pendiente de verificación.
- Si el examen incluye un **cuaderno de imágenes** separado (frecuente en el MIR — radiografías, ECG, lesiones dermatológicas asociadas a preguntas específicas), aportarlo también; es un componente image-heavy característico de este examen.

## Nomenclatura

Usar siempre el patrón `Examen_MIR_{año}.pdf` y `Plantilla_Respuestas_MIR_{año}.pdf` (o `_provisional` / `_definitiva` cuando corresponda) para que el proceso de extracción los identifique automáticamente por convención de nombre.
